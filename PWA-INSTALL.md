# Installing StreamArena as a PWA

The installable PWA flow targets Google Chrome on Android and desktop. StreamArena remains a website; this does not create a native app or publish anything to an app store.

## Android (Chrome)
1. Open the StreamArena HTTPS website in Chrome.
2. Wait for Chrome to offer installation; the in-page **Install App** button appears only when Chrome emits its install prompt.
3. Select **Install App** and confirm in Chrome, or use Chrome's menu and choose **Install app** if offered.

## Desktop (Chrome)
1. Open StreamArena in Chrome.
2. Use the install icon in the address bar or Chrome's menu option if shown.

## Not included
- Native Android/iOS apps or app-store publishing.
- Live video, chat, sign-in and streaming still require an internet connection.
- Offline support is limited to a simple offline notice and the query-free root app shell. Auth callback URLs, private account data, API responses, chat and LiveKit media are not cached.
- A PWA cannot guarantee background live broadcasting or capture another app/game's screen.
- Installation visibility depends on Chrome's installability checks and a successful HTTPS deployment.
